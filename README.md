Resume Assistant – Backend Team 

General Overview
The backend for the Resume Assistant is responsible for processing user information, managing resume and job-posting data, and providing the functionality needed to analyze resumes against job listings.
The backend is built using Python, Django, and MongoDB.

Technology Stack: 

Language: Python
Framework: Django
Database: MongoDB

Backend Responsibilities 
The backend team is responsible for:
Accepting job postings provided by users
Securely storing user resumes, skill information, and other profile data
Parsing resumes and job listings into information that can be analyzed
Creating and managing user skill banks
Supporting multiple resumes or profiles for a single user
Developing prompts for the AI resume/job-match analysis
Integrating the AI analysis system
Providing backend support for resume and profile updates
